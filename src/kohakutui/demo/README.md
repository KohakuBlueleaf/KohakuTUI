# kohakutui/demo/

Runnable demos; each is also a usage example of the public API.

## Files

| File | Responsibility |
| ---- | -------------- |
| `chat.py` | A fake assistant: composer with slash commands, streamed Markdown, a picker and a confirm dialog |
| `train.py` | A fake training loop: progress, a loss sparkline with NaN gaps, stats, captured `print` |
